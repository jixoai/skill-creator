# 1:1 复刻对照清单

## Context

本清单固定对照 ZCode v3.14.3，源码 checkout `/tmp/ia-redesign/zcode-src`，commit `29628c9`。引用均指向该 checkout 的真实源码。当前实现基准是本仓 `webui/src/lib/apps/agent/` 与 `webui/src/lib/components/agent/`；4.2 实施只触及 `components/agent/**` 与对应测试，不复制 React 组件，也不改 daemon 契约或 Agent 页面布局。

ZCode 左栏实际是 Workspace 内的任务/会话导航；它包含分组和 Workspace 两种组织方式、Workspace purpose sections、Pinned、Timeline 和 Archived。Automations 是独立主视图入口，不是左栏任务列表的同级标签。右侧是一个多 tab、单活动内容的 side pane。4.1 已 pin `@deepseek-ai/dsh-web-frontend@0.1.6-alpha.1` 作 Chat 可见行为基准；构建产物没有源码，源码级对照以 ZCode renderer 为准，不从 bundle 反推内部结构。

## Goals / Non-Goals

**Goals:** 固定 ZCode 的可见信息架构、布局尺寸、状态生命周期、焦点和快捷键；把每项差距落到本仓源文件和可独立验收的后续任务；将本轮可证实事实与缺失基准明确分开。

**Non-Goals:** 本轮不修改运行时代码；不迁移 React；不把 ZCode 私有业务模型直接搬进 Skill Creator；不臆造 ZCode 未实现的终端 shell 选择、终端拆分/最大化、独立图像 tab 或全局状态栏。

## Decisions

1. **React 只作行为和结构基准。** 复刻在现有 Svelte 5 页面和 store 内实现；数据身份、proposal approval 和 terminal 协议继续沿用本仓 contract。备选是移植 ZCode React 组件，拒绝它会引入第二套框架和组件状态边界。
2. **任务语义与 Agent session 语义分开。** ZCode 行为可移植到结构和交互，task-only mutation 不直接映射到 DSH session。备选是把 session 当 task 并显示同名操作，拒绝它会呈现不真实的动作和状态。
3. **右栏按单一 pane host + 多 tab 建模。** 一个 Workspace/Agent page 拥有 tab collection 与 active id，单次渲染一个 panel body；Agent event 通过带源 session/target 的 typed request 激活或新建 tab。备选是继续用三个固定 tab，无法承接多种 Agent 输出。
4. **设备偏好只存几何与显隐。** 树折叠、宽度、终端高度和面板打开状态写 DevicePrefs；当前 session、panel tab context 与 transcript 继续由 URL/store/daemon 维护。备选是将整棵树或内容状态塞进 localStorage，违反本仓状态分层。
5. **Chat 双源基准按可见能力分层。** 4.1 已 pin 与 `dsh-base` 同版的 `@deepseek-ai/dsh-web-frontend@0.1.6-alpha.1` 作黑盒行为基准；它没有源码，源码级结构/行为对照以 ZCode renderer 为准。静态启动失败的 DSH 行为保持未观察，不从 bundle 推断。备选是从 `@deepseek-ai/dsh-web` capability package 推断 UI，包职责不支持这种推断。
