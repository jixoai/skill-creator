# skill-creator 品牌图标使用说明书

## 1. Color Symbol（全彩渐变版）

**它的角色：** 品牌的“门面担当”。它拥有丰富的色彩和渐变细节，最能传达“吞噬信息、创造元能力”的黑洞概念，视觉冲击力最强。

**使用原则：** 只要条件允许（能展现全彩、屏幕分辨率高、印刷工艺好），就优先用它。

**生活与品牌化场景举例：**

- **数字产品的核心阵地：** 你的官方网站顶部导航、App 的启动开屏画面、微信公众号或 Instagram 的头像。
- **高质量的周边产品：** 采用数码直喷工艺的高级纯白 T 恤、色彩饱满的亚克力钥匙扣、笔记本电脑上的高光贴纸。
- **宣传物料：** 高清打印的展会海报、产品发布会上的巨幅背景板。

---

## 2. Flat Symbol（扁平纯色版）

**它的角色：** 品牌的“全能替补”。它去掉了复杂的渐变，只保留了核心的线条和色块（通常使用品牌主色调 `oklch(0.841 0.238 128.85)`），更加清爽、简约。

**使用原则：** 当环境不支持复杂颜色过渡，或者你需要一种更加现代化、克制的视觉风格时使用。

**生活与品牌化场景举例：**

- **日常办公与印刷：** 公司的信纸抬头、发票盖章旁边的标志、PPT 模板的角落（避免喧宾夺主）。
- **低成本或限制颜色的实体周边：** 采用丝网印刷（只能印单一或少数几种纯色）的环保帆布袋、马克杯。
- **极简数字 UI：** 作为一个功能按钮的图标，或者在一些背景比较复杂的网页区域，扁平版比渐变版更容易看清。

---

## 3. Monochrome（高清单色版）

**它的角色：** 品牌的“西装领带”。它是黑白的，但保留了极致的线条细节，给人一种高级、克制、甚至带点神秘和艺术感的氛围。

**使用原则：** 用于高端质感表达，或者只能使用纯黑/纯白一种颜色，且展示面积足够大（能看清细节）的地方。

**生活与品牌化场景举例：**

- **特殊工艺的高端周边：** 黑色磨砂保温杯上的**激光雕刻**（刻出来是银白色的细线）、皮质笔记本封面的**凹凸压印**（烫印）。
- **艺术化包装：** 采用极简冷淡风的快递包装盒（牛皮纸上只印一个纯黑的高清黑洞）、寄送邀请函时的火漆印章。
- **水印与底纹：** 作为视频画面的半透明保护水印，或者把它放大虚化后作为网页的纯色背景底纹。

---

## 4. Monochrome Mini（小容器单色版）

**它的角色：** 品牌的“微雕大师”。它加粗了线条、减少了过密的细节。因为之前的版本一旦缩小到指甲盖那么大，线条就会糊成一团，而这个版本在极小尺寸下依然清晰。

**使用原则：** 仅限于极小尺寸、极小空间的展示，或者极低分辨率的显示设备。

**生活与品牌化场景举例：**

- **操作系统的角落：** 电脑浏览器的标签页图标（Favicon，网页标题旁边的小图标）、手机顶部的通知栏小图标（Tray Icon）、智能手表的微小界面。
- **微型实体标签：** 缝在 T 恤袖口或衣领上的那块极小的水洗标、U 盘上指甲盖大小的丝印。
- **极简数字外设：** 机械键盘上一颗定制的纯黑透光键帽（如果线条太细，光会透不过来，Mini 版刚刚好）。
